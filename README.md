# Business Forecasting Capstone Project

This repository contains my final capstone project on business forecasting, completed as part of my MBA Business Analytics program at the University of Maine.

## Introduction

### Business Interest and Objective
**Sales Performance Analysis**

The business aims to understand how different product categories are performing to guide strategic decisions on warehouse expansion. Specifically, we want to identify:
- Which product categories are producing higher sales so inventory levels can be increased.
- Which categories are underperforming and may be considered for discontinuation.

### The Problem to Solve
- **Increase inventory** for categories with strong sales performance.
- **Eliminate or reduce focus** on categories with poor sales performance.

The data for this project was sourced from Kaggle.

## Project Overview

This project applies time series forecasting and sales performance analysis to aid business decision-making. The methods used include:
- Time Series Decomposition
- Stationarity Testing (ADF Test)
- Forecast Modeling (ARIMA, Holt-Winters Exponential Smoothing, etc.)
- Model Evaluation Metrics (RMSE, MAPE)

## Tools and Technologies
- **R Programming Language**
  - Libraries: `forecast`, `tseries`, `ggplot2`, `dplyr`
- **Excel**: For preliminary data exploration

## Results Summary
Based on the forecasting models, the project identifies the most and least performing product categories, enabling the business to:
- Optimize inventory management.
- Strategically plan warehouse expansion based on product demand.
